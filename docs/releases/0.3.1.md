# 0.3.1 — Icon selection through Icones

Workflow 1.3.1 prioritizes https://icones.js.org/ when selecting new icons. Icones explores Iconify collections; the agent must still choose a coherent family, verify real icon IDs and the collection's license, use the project's integration, and record relevant provenance. Existing families remain the starting point for refinement and reference replication. Small token tasks and grill-me do not acquire an icon migration requirement.

The policy is shared by SKILL.md, the reuse guide, the handoff skeleton, MCP initialization instructions, get_workflow, resources, prompts and exported workflow guides. No icon assets or new icon runtime dependency are added. Existing applications are not migrated to a different icon family.
