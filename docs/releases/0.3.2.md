# 0.3.2 — Koboyo resource guidance

Workflow 1.3.2 adds Koboyo Icons as the preferred source when a confirmed design direction calls for hand-drawn icons or illustrations. Icones remains the default discovery source for interface icons, and existing project families/integrations remain the starting point for scoped refinements.

The shared skill, reuse guide, handoff skeleton and MCP initialization instructions explain how to verify real asset pages/slugs, select a consistent drawing style, inspect SVGs, integrate only needed local assets and record provenance. Koboyo assets are not Iconify IDs. Its custom license allows some product use and limits redistribution, competing products and asset-picker/export use; the workflow requires checking the actual intended use. No Koboyo assets, picker, API integration or third-party runtime dependency are included in Token Studio or the packages.

Primary sources checked 2026-10-19: [catalog](https://koboyo.com/icons), [example asset](https://koboyo.com/icons/account-deletion-request), [license](https://koboyo.com/icons/license).
