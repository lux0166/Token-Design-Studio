# Token Design Studio 0.2.1

## Changes

The shared CLI/source skill installer stages a complete tree, preserves unmanaged files, serializes cooperating installers, revalidates the destination and swaps directories with a retained backup. A transaction journal enables recovery after interruption. Customized owned files and file/directory conflicts stop before replacement. Repeated identical installs do not create backups.

Codex setup creates a missing CODEX_HOME, prepares the skill before changing MCP configuration, and compensates its own changes on failure. Concurrent config edits are retained and reported for manual reconciliation with backups. External CLI calls have a 30-second timeout. A crash during an external config command can leave an uncertain outcome: the journal and backup are retained rather than guessing and overwriting newer settings. A stale installer lock takes up to two minutes to recover; ordinary server locks retain their existing behavior.

install-skill no longer depends on PORT or a running server. Existing full-package commands and data formats remain compatible. No real user skill, Codex configuration or application data was modified in tests.

The final artifact also includes the compatible path-alias fix discovered on macOS CI: starting again through a symlink/junction reuses the same real data store. Reproduce it with `npm run pack:legacy`: the script archives milestone c3e8142, overlays the current compatible main/codex/install-core CLI files, runs the 27-test legacy suite and builds the 0.2.1 editor/runtime with workflow 1.2.0. It does not copy 0.3 task features into the old release. Both tarball versions are then exercised by the same version-aware package verifier, including alias reuse.

## Verification

27 automated tests passed on Windows / Node 24.19.0. Seven transaction regressions cover post-preflight edits, PORT isolation, path conflicts, another installer process, failed swaps, interrupted installs, fresh CODEX_HOME, setup compensation and concurrent configuration edits. A Node 22.12 / 24 matrix for Windows, macOS and Linux is configured in GitHub Actions; remote CI results are not claimed as executed locally.

The clean-tarball integration checks passed all nine groups: executable discovery, built editor assets, real stdio/HTTP MCP, persistent writes, cross-port locks, crash/restart, migration, isolated real Codex setup and unrelated port conflicts. Release is a local tarball; no npm publication was performed. The final checksum is recorded in artifacts.json (the initial pre-CI tarball was superseded by the compatible path-alias backport).
