# Lịch học — synthetic grill-me fixture

This example demonstrates a completed specification dossier, not a built product or a real user interview. The fixture supplies its answers explicitly.

Actors: center administrator and teacher. Goal: find today's next one-to-one English lesson. Records contain learner, teacher, local date/time, level and lesson status. Clearly flag conflicting teacher/time assignments. This fixture covers a local prototype; authentication, live video, payments and cloud integrations are outside scope.

Acceptance: the specification identifies both actors, required lesson fields, conflict behavior and scope. A future implementation must show today's lessons with those fields and allow opening lesson details. Grill-me ends here and makes no code/render claim.
